Privacy

Bonfire runs in this browser. It reads the page already open in your tab. It does not upload that page, your clipboard, or your scores. There is no account and no Bonfire server in this version.

Stored on your device

  • Settings (copy guard, badge, checkout checks, sensitivity), synced with Chrome if you use Chrome sync.
  • Last 5 hostnames plus score, issue count, and time — local only, shown only if you open Recent.
  • A count of copy-guard events. Copied text itself is not saved.

Not stored

Page HTML, passwords, payment fields, and clipboard contents are not written to extension storage. Clearing Recent or uninstalling removes local Bonfire data.

Permissions

All-site access exists so the checker can run on ordinary http/https pages. There is no remote dashboard using that access.
